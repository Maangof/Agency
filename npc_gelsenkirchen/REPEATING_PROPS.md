# Повторяющиеся вещи для заполнения карты — предложение

10.10.2026. Что уже есть в игре: мусорка (синяя), шкафчики, электрощит, европоддон, деревянный ящик, sci-fi контейнер,
морской контейнер, бетонные блоки, модули барьера, генератор поля, маяк, кейс энергоячеек, брошенные машины,
3 декали мусора. Ниже — чего не хватает, по приоритету. **Жирным** — то, что сильнее всего «оживит» улицу.

## 1. Улица — каждые 10–30 м (самое заметное)

| Вещь | Зачем / где | Взаимодействие |
|---|---|---|
| **Мусорный контейнер 1100 л на колёсах** (серый, с крышкой) | у каждого подъезда, во дворах; главный «немецкий» признак улицы | лут как в мусорке, укрытие |
| **Мешки «Gelber Sack» и кучи мешков** | у контейнеров и стен, много | — |
| **Sperrmüll** — матрас, диван, холодильник, шкаф на тротуаре | у домов без поля (выселенных) | матрас/диван — укрытие |
| **Фонарный столб** (рабочий / погасший / упавший) | вдоль улиц каждые ~25 м; дефицит света — горит каждый 4-й | — |
| **Дорожные знаки, столбики-боллардов, велопарковка** | перекрёстки, тротуары | — |
| **Брошенные велосипеды и самокаты** | у стоек, на тротуаре | — |
| **Тележки из супермаркета** | у Späti, у баррикад | толкать (позже) |
| **Glascontainer / контейнер для одежды** | площади, парковки | лут: бутылки (пфанд), одежда |
| **Litfaßsäule** — тумба с афишами (карантинные объявления) | площади, перекрёстки | читать: слухи, задания |
| **Жёлтый почтовый ящик Deutsche Post** | у почты, на углах | лут: письма (сюжет) |

## 2. Карантин и ликвидаторы

| Вещь | Где |
|---|---|
| **Прожекторная мачта / вышка контроля** (sci-fi текстуры) | кордон, КПП, у постов ликвидаторов |
| **Лента «Quarantäne», таблички «Sperrzone»** | двери опечатанных домов, проходы |
| **Бочки с маркировкой опасности, контейнеры дезактивации** | у руин, у постов |
| **Душ дезактивации / палатка** | у шлюзов, на КПП |
| **Кабели по земле от генераторов** | от пилонов поля к домам |

## 3. Жилые дома («Оставшиеся», дома под полем)

| Вещь | Где |
|---|---|
| **Свечи и лампы в окнах** (свет только у живых) | окна жилых домов — главный признак «тут живут» |
| **Бельё на верёвках, спутниковые тарелки, кондиционеры** | балконы, фасады |
| Генераторы и солнечные панели на балконах, бочки для дождевой воды | балконы, дворы |
| Голубятни, поленницы | крыши, дворы |

## 4. Фракции (немного, но узнаваемо)

| Фракция | Вещи |
|---|---|
| Секта дыма | белые ленты на решётках, курильницы, дымоходы-трубы из окон, меловые знаки (декали) |
| Бандиты | колючая проволока, «ежи», листы железа на окнах, бочки-костры, метки «Schutzmarke» (декали) |
| Торговцы | вывески-стрелки, ящики с товаром, тенты, весы |

## 5. Интерьеры (комнаты, Kaufhof, вокзал)

Стулья, столы, полки, холодильник, раковина, диван, шкаф, батарея, коробки, бутылки, банки, кучи одежды, трубы.

## 6. Декали (дёшево, много)

Лужи, трещины, люки и решётки стока, граффити, сорванные афиши, следы гари, серая корка у руин, разметка «шлюз».

---

**Предлагаемый порядок:** 1) мусорный контейнер 1100 л + мешки + Sperrmüll, 2) фонари (горит каждый 4-й) и свечи в окнах
жилых, 3) вышка контроля и прожекторы (sci-fi), 4) велосипеды, тележки, знаки, 5) декали луж и граффити.
Модели — из ваших загрузок (CC0) или смоделирую сам; подготовку в Blender — на ПК-сессии, расстановку — по тем же правилам
(дом без поля / под полем, зона лута).
