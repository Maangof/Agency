# Шрифты для текстур реквизита

Источник: репозиторий Google Fonts (github.com/google/fonts), скачаны 2026-10-09.
Используются только для генерации картинок (этикетки, постеры, меню) в `make_prop_textures.py`;
в игру попадают как часть текстур, сами файлы шрифтов в игру не входят.

Обе лицензии разрешают коммерческое использование, в том числе в изображениях.
