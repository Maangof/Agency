# Клуб «Neon» — что нужно для детальной прорисовки (на согласование, 2026-10-09)

**Ничего не скачано.** Список составлен по правилам проекта (`docs/ASSET_SOURCES.md`, `docs/CREDITS_ASSETS.md`):
- берём только **CC0** (Poly Haven, ambientCG) и **CC-BY** (с автором в титрах);
- не берём NC, ND, SA и «Personal use»;
- бренды — только пародийные.

**Что доступно из облака.** Poly Haven, ambientCG, Sketchfab, Kenney и Quaternius закрыты политикой сети — я проверил,
соединение отклоняется. Открыт только GitHub, то есть модели Khronos glTF Sample Assets. Поэтому:
- **☁ облако** — могу скачать сам, здесь и сейчас;
- **🖥 ПК** — качает сессия на ПК через готовый `tools/FetchHubAssets.tscn` (Poly Haven по id) или вручную (Sketchfab).
  Списки уже лежат в `tools/hub_assets.json`, туда добавятся новые id;
- **✎ сделаю сам** — процедурно или в Blender, без загрузок: этикетки, постеры, вывески, меню, мелкий реквизит.

Отдельно про LFS: облачная сессия не может загрузить файлы LFS в `pfeffi-game`
(см. `docs/HANDOFF.md`). Бинарные ассеты всё равно коммитит сессия на ПК; из облака уходят только списки и скрипты.

**Разрешение.** 2K — для игры (стены, мебель), 4K — только для героев кадра: стойка, кирпич за баром, сцена.
Оценка объёма: текстуры 2K ≈ 15 наборов × 12 МБ ≈ 180 МБ; модели ≈ 25 × 5–20 МБ ≈ 250 МБ.

## C. Мелочи и «жизнь» (делаю сам ✎, без загрузок)
- **Бутылки** — 6–8 форм: водка, джин, ром, ликёр, пиво 0,33, «Korn». Этикетки — пародийные марки:
  «Gelsen Korn», «Zeche Pils», «Blau-Weiß Bräu», «Kohlenpott Kräuter».
- **Стаканы**: пивная кружка, «Stange», шот, коктейльный; подставки под пиво с логотипом клуба.
- **Меню и доски**: доска с ценами над стойкой, меню на столиках, табло «Currywurst/Pommes» у окна выдачи.
- **Постеры и наклейки**: концерты, «Blau-Weiß 04», плакаты карантина с юмором («Nur mit Maske tanzen»), граффити в WC.
- **Реквизит**: пепельницы, салфетницы, кеги и пивные ящики, огнетушитель, знаки «Notausgang», кабели на сцене, микрофон,
  вешалка с куртками, ведро со шваброй, сушилка для рук, диспенсер мыла, бумага.
- **Кухня**: сковороды, кастрюли, гастроёмкости, ножи на магнитной планке, тарелки с карривурстом, бутылки соусов, вентиляция.
- **Свет**: неоновые трубки нужного изгиба (сделаю кривыми с толщиной), лампы накаливания с нитью.
- **Износ** (важно для лора): потёртости на полу у стойки, следы обуви, пятна на столешницах, сколы кирпича.
  Это маски грязи в материалах, без новых файлов.
